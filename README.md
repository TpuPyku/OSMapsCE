# OSMapsCE

Карта [OpenStreetMap](https://www.openstreetmap.org) с пробками, поиском и маршрутом для навигаторов и
магнитол на Windows CE (экран 800×480). Для MMC Лады Веста (до 2021 года) с оболочкой VestaHome поддерживаются цветовые темы и виджет главного экрана.

![Скриншот](OSMaps.jpg)

## Возможности
- Карта OpenStreetMap на весь экран; просмотренные места кэшируются и открываются без интернета.
- Пробки Яндекса или 2ГИС поверх карты, обновление раз в 10 минут, суточные лимиты запросов.
- GPS: машина на карте, режимы «север вверх» и «по курсу».
- Ночная карта.
- Поиск адресов и мест, маршрут с подсказками манёвров и перестроением при съезде. Необходим интернет.
- Варианты маршрута с оценкой времени.
- Редактор маршрута: долгое нажатие на карту — «Куда», до трёх точек «Заехать», своё «Откуда».
- На Lada Vesta с [VestaHome](https://github.com/TpuPyku/VestaHome): цвет темы VestaHome и виджет карты на её
  главном экране.

## Установка
1. Скачать архив из [Releases](../../releases), распаковать папку `OSMapsCE` на карту памяти.
2. Запустить `OSMapsCE.exe`.

Рядом появятся `OSMapsCE.ini` (настройки) и папка `Cache` (плитки).

## GPS
Программа только читает порт GPS и выбирает из потока строки NMEA. По умолчанию `COM6:` 115200; для другого
устройства — «Настройки → Поиск GPS» (перебор COM1…COM9 и скоростей) или порт и скорость вручную.
- Счётчик NMEA в настройках не растёт — не тот порт.
- Много строк с ошибкой — не та скорость.

## Настройки (`OSMapsCE.ini`)
Почти всё меняется на экране; файл правят при закрытой программе.

| Ключ | По умолчанию | Описание |
|---|---|---|
| `traffic_src` | yandex | источник пробок: yandex / 2gis |
| `traffic_ttl` | 10 | обновление пробок, минут |
| `yandex_limit`, `2gis_limit` | 900, 2000 | запросов пробок в сутки |
| `auto_reserve` | 100 | запас лимита для ручных обновлений |
| `api_limit` | 300 | запросов поиска и маршрута в сутки |
| `cache_mb` | 500 | размер кэша карты, МБ |
| `cache_days` | 7 | через сколько дней сверять плитку с сервером (0 — никогда) |
| `gps`, `gps_port`, `gps_baud` | 1, COM6:, 115200 | GPS вкл/выкл, порт, скорость (0 — не менять) |
| `kill` | CityGuideCE.exe | программа, которую закрыть, если держит порт GPS (пусто — никогда) |
| `hide_taskbar` | 1 | скрывать панель задач |

Остальные ключи — состояние программы и счётчики.

## Источники и их правила
- **Карта** — плитки [OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/) по HTTPS, с кэшем;
  массовая выкачка запрещена. Данные © участники OpenStreetMap, [ODbL](https://www.openstreetmap.org/copyright).
- **Пробки Яндекса** — Static API без ключа; при регулярном превышении лимита доступ блокируется.
  [Условия](https://yandex.ru/dev/commercial/doc/ru/).
- **Пробки 2ГИС** — плитки сервера библиотеки [RasterJS API](https://github.com/2gis/mapsapi) (более 200 городов),
  адрес может измениться; только некоммерческое использование по
  [лицензии 2ГИС](https://github.com/2gis/mapsapi/blob/master/LICENSE).
- **Поиск** — [Photon](https://photon.komoot.io), запрос только по кнопке «Найти».
- **Маршрут** — OSRM на серверах [FOSSGIS](https://routing.openstreetmap.de), без учёта пробок.

Поиск и маршрут — бесплатные серверы для умеренного использования, отсюда лимит `api_limit`.

## Если что-то не так
- `OSMapsCE.log` — запросы, ошибки сети, GPS, кэш (до 256 КБ, прошлая часть — `OSMapsCE.old.log`).
- «Ошибка HTTPS» — чаще всего неверная дата на устройстве и нет сигнала GPS.
- Удалите `OSMapsCE.ini` — вернутся настройки по умолчанию; папку `Cache` можно удалить.

## Сборка
C++, Win32 API, исходники в [native_osm](native_osm). Нужна Visual Studio 2005 с Smart Device и SDK Pocket PC 2003.

1. `git submodule update --init` — модуль [VestaCore](https://github.com/TpuPyku/VestaCore) в `core` (GPS).
2. `native_osm\build_bearssl.bat` — один раз, BearSSL для ARM и x86.
3. `native_osm\build.bat` — `OSMapsCE\OSMapsCE.exe` (ARMv4, Windows CE) и `OSMapsCE\OSMapsPC.exe` (проверка на ПК:
   стрелки, `+`/`-`, колесо — масштаб; `T` пробки, `L` источник, `G` GPS, `S` настройки, `F3` поиск).

Служебные: `native_osm\make_ta.py` — корневые сертификаты; `native_osm\make_regions.py` — города 2ГИС
(нужен ключ в `native_osm\.env`, в программу не входит).

Сторонние библиотеки: [BearSSL](https://bearssl.org) 0.6 (MIT) — HTTPS; [stb_image](https://github.com/nothings/stb)
(public domain) — PNG/JPEG. Подробнее — `THIRD_PARTY.txt`.
