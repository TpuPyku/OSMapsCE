# OSMapsCE

**[English version](README.en.md)**

OSMapsCE — навигатор на картах [OpenStreetMap](https://www.openstreetmap.org) для устройств на Windows CE с экраном
800×480. Главное устройство — головное устройство (ГУ) MMC Lada Vesta. Программа показывает карту и пробки, ищет адреса,
строит маршрут и ведёт по нему голосом. Поиск, маршруты и векторная карта работают и без интернета, если скачать карты
областей. Программа бесплатная.

Версия программы видна в «Настройки → О программе». Номер вида `2.1.ГГММДД`: в конце стоит дата сборки.

## Возможности

- **Карта.** Растровая (плитки OSM) или векторная (OpenFreeMap). Дневная и ночная. Вид от третьего лица («3D»).
  Просмотренные места сохраняются в кэш.
- **Без интернета.** Скачанная область даёт векторную карту, поиск адресов и маршруты. Между областями маршрут идёт
  по магистралям.
- **Пробки** Яндекса или 2ГИС: на карте или только на линии маршрута. Время в пути с учётом пробок.
- **Маршрут:** своё начало пути, до трёх промежуточных точек, несколько вариантов на выбор, объезд платных дорог.
- **Навигация:** карточка манёвра, схема сложной развязки, время прибытия, перестроение при съезде с маршрута.
  В тоннеле без GPS метка едет по маршруту дальше. После перезапуска программа предлагает продолжить маршрут.
- **Голосовые подсказки** на русском или английском, без интернета. На Lada Vesta звучат поверх радио.
- **Избранное:** до 12 мест, у каждого свой значок.
- **Слои скачанной области:** светофоры, неровности с предупреждением в пути, парковки, платные парковки Москвы
  с ценой. Знак ограничения скорости дороги.
- **Языки интерфейса:** русский и английский. Новый язык — один текстовый файл.
- **С VestaHome:** виджет «Карта OSM» на главном экране, цвет темы, общий режим «день / ночь», манёвр в верхней
  строке VestaHome, масштаб кнопками руля.

## Установка

1. Скачайте архив `OSMapsCE-<версия>.zip` из [Releases](../../releases).
2. Распакуйте папку `OSMapsCE` на карту памяти устройства.
3. Запустите `OSMapsCE.exe`.

Подробно — в [руководстве пользователя](docs/manual.md).

## Сборка

C++, Win32 API, исходники в [native_osm](native_osm). Нужна Visual Studio 2005 с Smart Device и SDK Pocket PC 2003.

1. `git submodule update --init` — модуль [VestaCore](https://github.com/TpuPyku/VestaCore) в `core`.
2. `native_osm\build_bearssl.bat` — один раз, BearSSL для ARM и x86.
3. `native_osm\build.bat` — `OSMapsCE\OSMapsCE.exe` (ARMv4, Windows CE) и `OSMapsCE\OSMapsPC.exe` (проверка на ПК:
   стрелки сдвигают карту, `+`/`-` и колесо — масштаб; `T` пробки, `L` источник, `G` GPS, `S` настройки, `N` ночь,
   `F3` поиск, `Esc` выход).

Проверки: `native_osm\test_offline.bat`, `test_vtile.bat`, `test_ui.bat` (маршрут и переводы), `test_stamp.bat`,
`test_voice.bat`, `python -m unittest test_maps` в `offline\test`. Сборка карт — [offline](offline) и workflow `maps`.

Служебные: `core\make_ta.py` — корневые сертификаты; `native_osm\make_regions.py` — города 2ГИС (нужен ключ в
`native_osm\.env`, в программу не входит).

Сторонние библиотеки: [BearSSL](https://bearssl.org) 0.6 (MIT) — HTTPS; [stb_image](https://github.com/nothings/stb)
(public domain) — PNG/JPEG. Подробнее — `THIRD_PARTY.txt`.
